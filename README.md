
# Enterprise Security Audit and Risk Assessment

## Week 4 - Cybersecurity Internship

### Objective
To assess security controls in a simulated enterprise
environment and recommend improvements.

### Technologies
- Python
- VS Code
- NIST Cybersecurity Framework
- CIS Controls (Reference)

### Audit Areas
- Application Security
- Network Security
- Access Control
- Database Security
- Security Monitoring

### Features
- Virtual Asset Inventory
- Simulated Security Findings
- Risk Classification
- Security Recommendations
- Remediation Roadmap

### How to Run
python security_audit.py

### Note
This project demonstrates a simulated security audit.
Findings are illustrative and do not represent a live
enterprise vulnerability scan.
